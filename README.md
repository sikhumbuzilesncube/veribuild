# VeriBuild

**A product of GatekeeperAI**

AI-powered Bill of Quantities (BOQ) generator for construction plans in Zimbabwe.

## Features
- Upload floor plans (PDF, JPEG, PNG)
- AI reads and extracts room dimensions, doors, windows
- Generate professional BOQs in 3 minutes
- Compare prices from multiple hardware stores
- Get skilled worker recommendations
- EcoCash payment integration

## Tech Stack
- Next.js 14
- Supabase (PostgreSQL + Storage)
- Tesseract.js for OCR
- Vercel for hosting
